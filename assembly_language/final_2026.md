# 汇编语言 2026 年期末考试回忆

根据以往学长的回忆，汇编语言并不是一门非常“重磅”的课程，但今年的情况有所不同，据我所知，很多优秀的同学取得的分数并不十分理想（当然，也算不上十二分惨烈）。首先，这门课的老师（肖junhua老师）是一位很好的老师，并且汇编语言的知识会在后续的一些课程（如体系结构，甚至计算机组成原理）中反复出现，所以是否选择这门课程，同学们自行斟酌。且每年情况不一，理性看待。

无期中考试。期末考试从题库里出，考试之前老师大致过了一遍题库的内容，大约包含以下要点：

## 题库

- 哪个不能作为变址/索引寄存器参与 x86 复杂寻址（SIB 寻址）？`%esp`（`%esp` 可以作基址寄存器，但不能作索引寄存器）
- 寻址方法：`disp(base,index,scale)`，如 `4(%ebp,%esi,8)`；注意不能把 `%esp` 写成带比例因子的索引寄存器
- `EFLAGS` 标志位
- 给一段代码，算符号位等标志位，或者考 `movswl`（符号扩展：word -> long）是什么样的
- `loop` 指令的基本操作
- `test` 指令做按位与操作，只设置标志位，不保存结果
- `switch-case` 结构：编译器在合适条件下会转换成跳转表（jump table）
- `if-else` 语句的汇编是什么样的
- 条件传送指令 `cmovcc`（conditional move）是什么样的
- 栈的生长方向、栈帧布局是什么样子的
- `call` 指令大概是什么样的操作
- 参数传递大概是什么样的
- `leave` 指令的大概实现
- x86-64/Linux 中当一个函数传了七个整型参数，第七个参数通过什么传递？
- `lea` 指令是什么功能：不访存，只做地址/整数表达式计算
- 二维数组的访问，地址是怎么计算的，计算 `a[i][j]`
- 结构体对齐
- 联合体占多大的空间
- 各种结构中，结构成员的起始地址/偏移量
- GCC 内联汇编 `asm volatile` 的作用/属性
- 内联汇编对编译器优化的影响
- GCC 内联汇编 `clobber` 列表是什么含义
- 位操作：`bt` 指令是干啥的，`bsf` 指令是干啥的，`lock` 前缀是干啥的，`memory` clobber 是干啥的
- `memory` clobber 做了哪些约束；优化里区分循环展开和软件流水
- 把大写转换成小写的函数，里面的 `for` 循环为什么是 O(n^2)
- 循环展开到底是什么样的
- CPE（cycles per element）的计算
- 矩阵乘法三层循环，哪一种循环排列的 cache 利用率最高？
- ELF 格式中 segment 和 section 的区别
- GOT 表和 PLT 协作的机制到底是什么样的
- 64 位环境栈帧的布局，从低地址到高地址到底是什么样的排列
- 栈保护/栈金丝雀（stack canary）一般存在什么位置
- Meltdown 攻击的主要原因是什么
- x86-64 System V ABI 中，栈在调用点按 16 字节对齐
- 二维数组的排列是行优先的
- 假设一个联合体里面包括两个结构体，知道每个变量的偏移大概是多少
- 小端序（little endian）的内存布局大概是什么样子的
- 字符串指令，如 `movsb` / `movsw` / `movsl` 或 `rep movsl`，要知道 `%esi`、`%edi`、`%ecx` 大概是什么含义
- `bt` 指令干了什么事情

## 程序改错

- 分配栈空间时要注意栈对齐
- 字符串拷贝的时候尾部要添加 `\0`

## 读程序

- 链表遍历
- 递归函数
- 字符串操作（求长、字符串拷贝、字符串拼接、`memcpy`、`memset`、排序、反转字符串）
- C 里面一些结构体/联合体的访问
- `spinlock`（自旋锁）的一些基本实现
- CPE 是干啥的
- 双路循环展开为什么会有优化这么好的效果
